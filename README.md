# Luma Motion

An interactive slider library showcase for React and vanilla JavaScript.

Luma Motion lets people explore polished slider patterns in a live playground before copying the implementation. The preview supports arrows, pagination, drag/swipe gestures, keyboard navigation, autoplay, search, category filters, code tabs, and copy-to-clipboard.

## Included slider patterns

- Aurora 3D
- Card stack
- Focus ring
- Editorial
- Product orbit
- Testimonials
- Marquee
- Image reveal

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the folder with any static web server.

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project files

- `index.html` — page structure and content
- `styles.css` — responsive visual system and slider compositions
- `app.js` — catalog, preview interactions, code tabs, filtering, and copy behavior
